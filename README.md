# 🎯 Cypress Locators & Assertions

## 📌 About the Project

This repository contains practical exercises focused on locating web elements and validating expected results using Cypress and JavaScript.

The goal is to build a strong foundation in UI test automation by practicing element selection, DOM traversal, and assertions.

## 🎯 Objectives

- Practice locating web elements using Cypress.
- Validate text, attributes, and element collections.
- Apply positive and negative assertions.
- Write clear and reliable automated tests.
- Combine locators and assertions to validate user flows.

---

### 🔎 1. Locators
**File:** `locators.cy.js`

**Objective:** Practice finding and selecting web elements using Cypress locators.

**Key concepts:**
- `cy.get()`
- `cy.contains()`
- CSS selectors
- Element identification and selection

---

### 🧭 2. Advanced Locators
**File:** `advanced_locators.cy.js`

**Objective:** Practice more advanced element selection techniques to locate specific elements on a web page.

**Key concepts:**
- Advanced element selection
- Text-based locators
- DOM traversal and element targeting

---

### 📝 3. Text Assertions
**File:** `text_assertions.cy.js`

**Objective:** Verify that web elements display the expected text and content.

**Key concepts:**
- `have.text`
- `contain.text`
- Text validation
- Expected versus actual results

---

### 🏷️ 4. Attribute Assertions
**File:** `attribute_assertions.cy.js`

**Objective:** Validate HTML attributes to ensure web elements have the expected properties.

**Key concepts:**
- `have.attr`
- Attribute values
- Element property validation

---

### 📋 5. Collection Assertions
**File:** `collection_assertions.cy.js`

**Objective:** Validate collections of web elements and verify that they meet expected conditions.

**Key concepts:**
- Element collections
- Element counts
- Collection-level assertions

---

### 🚫 6. Negative Assertions
**File:** `negative_Assertions.cy.js`

**Objective:** Verify that elements, text, or conditions do not exist or do not meet specific expectations.

**Key concepts:**
- `not.exist`
- `not.be.visible`
- Negative validation scenarios

---

### 🧪 7. Mini Challenge
**File:** `mini_challenge.cy.js`

**Objective:** Apply locators and assertions in a practical test scenario to validate expected application behavior.

**Key concepts:**
- Test scenario execution
- Element selection
- Assertions
- Expected behavior validation
